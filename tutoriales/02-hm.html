Capítulo 2: Git, control de versiones

INSTALACION EN LINUX En distribuciones basadas en Debian/Ubuntu: sudo apt install git Verificacion de la instalacion Sea cual sea tu sistema operativo, abre la terminal y ejecuta. git --version Deberias ver algo como: git version 2.43.0 Si ves un mumero de version, Git esta instalado. El numero exacto no importa mucho, cualquier version reciente funciona perfectamente:

config_Git.sh
|
