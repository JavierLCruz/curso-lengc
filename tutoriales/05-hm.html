Instalación en Linux

En distribuciones basadas en Debian/Ubuntu:

bash
$ sudo apt install git

Verificación de la instalación

Sea cual sea tu sistema operativo, abre la terminal y ejecuta:

bash
$ git --version
git version 2.43.0

Si ves un número de versión, Git está instalado. El número exacto no importa mucho, cualquier versión reciente funciona perfectamente.

Configuración inicial

Antes de hacer nada con Git, necesitas decirle quién eres. Cada commit quedará firmado con tu nombre y tu email, así que configúralos correctamente.

bash
$ git config --global user.name "Linus Torvals"
$ git config --global user.email "linus@mail.net"

Cambia "Linus Torvals" y el email por tus datos reales. Usa el mismo email que usarás en GitHub, GitLab o la plataforma que elijas.

El flag --global significa que esta configuración aplica a todos los repositorios de la máquina. Si algún día necesitas usar un email diferente en un proyecto específico, puedes ejecutar el mismo comando sin --global dentro de ese repositorio.

Configuraciones extra recomendadas

Rama por defecto: main

bash
$ git config --global init.defaultBranch main

Cuando creas un repositorio nuevo, Git necesita un nombre para la rama principal. Históricamente se usaba "master", pero el estándar moderno es "main". GitLab, GitHub y la mayoría de plataformas ya usan "main" por defecto.

Editor por defecto: nano

bash
# nano viene preinstalado por defecto en Debian
$ git config --global core.editor "nano"

Verifica tu configuración

bash
$ git config --list
user.name=Linus Torvals
user.email=linus@mail.net
init.defaultbranch=main
core.editor=nano

Si quieres ver un valor específico:

bash
$ git config user.name
Linus Torvals
$ git config user.email
linus@mail.net
