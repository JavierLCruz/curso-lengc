Capítulo 1: Tu primer "Hola Mundo"

Todo viaje en la programación en C comienza con la inclusión de las librerías estándar y la función main().

Para crear nuestro primer archivo, abriremos nuestro editor desde la terminal ejecutando nano hola_mundo.c y escribiremos el siguiente código:

nano hola_mundo.c
| 
#include 

int main() {
    printf("¡Hola, terminal Linux desde C!\n");
    return 0;
}

¿Qué acaba de pasar?

  • #include <stdio.h>: Importa las herramientas para Entrada y Salida (Standard Input/Output).
  • int main(): Es el punto de arranque de cualquier programa en C.
